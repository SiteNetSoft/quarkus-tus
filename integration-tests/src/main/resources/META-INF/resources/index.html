TUS console

Manual harness for the quarkus-tus extension — not part of the published library.

Server

Capabilities the server advertises via OPTIONS /tus.

Core upload — creation, chunking, resume

Pause mid-upload, then resume: the client re-reads the offset with HEAD and continues.

creation-with-upload

Sends the first bytes in the creation POST itself, saving a round trip.

creation-defer-length

Creates without a known size, then sets Upload-Length on the first PATCH.

checksum

SHA-1 computed in the browser. The bad case should be rejected with 460 and leave the offset untouched.

concatenation — parallel upload

Splits the chosen file into partials, uploads them concurrently, then merges with Upload-Concat: final.

expiration & termination

Upload-Expires is returned on creation; DELETE terminates. A second DELETE is idempotent.

SSE progress

Live upload-progress events for the current upload. Start this, then run an upload.
